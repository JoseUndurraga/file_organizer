# File Organizer

CLI Tool on python used for organization purposes on folders, clasification made by extensions.

## Qualities

- **Clasification:** files on selected or default folder get divided by extension on preset categories (`Datasets`, `Docs`, `Images` y `Not Considered`)
- **Memory usage:** by usage of generators lowers memory usage needed
- **Compatibility:** paths managed by `pathlib` natively

## Requirements

- Python 3.8 or higher (standard library usage)
